# 🎓 Tu Marca Academia — Sitio Web Informativo

Este es un proyecto real y desplegado en producción de una plataforma web informativa diseñada para una academia de cursos. El objetivo principal del sitio es presentar de forma clara la propuesta educativa de la academia, ofrecer un canal de captación directo a través de un formulario de contacto y centralizar la estrategia de contenidos en una sección de blog optimizada.

---

### 🚀 Características Principales
* 🎨 **Maquetación Visual de Alta Conversión:** Interfaz limpia y profesional diseñada para guiar al usuario hacia la información clave de los cursos.
* 📝 **Sección de Blog Dinámica:** Espacio optimizado para la publicación de artículos, ideal para el posicionamiento orgánico (SEO) y la autoridad de la marca.
* 📩 **Captación de Leads Directa:** Integración de un formulario de contacto funcional para recibir dudas, consultas e intenciones de inscripción de forma rápida.
* 🔌 **Lógica Personalizada:** Uso de snippets en PHP para extender el comportamiento nativo y mantener el sitio liviano y eficiente.

---

### 🛠️ Tecnologías y Herramientas Utilizadas
* **CMS:** WordPress
* **Maquetación y UI:** Elementor / Figma
* **Backend & Lógica:** PHP (Snippets y funciones del tema)
* **Entorno de Desarrollo Local:** LocalWP

---

### 📁 Estructura de este Repositorio
Para que el código sea fácil de revisar en mi portafolio, la estructura contiene:
* `/themes/`: Archivos clave del tema activo (`functions.php`, `style.css`) con los hooks y estilos personalizados.
* `/snippets/`: Fragmentos lógicos en PHP creados para optimizar o extender funciones específicas del sitio.
* `/templates/`: Esquemas estructurados y componentes visuales clave exportados de las páginas principales.
