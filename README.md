# Tu Marca Academia Website

Este repositorio contiene el contenido clave de WordPress para el sitio.

## Qué está incluido
- `wp-content/`
  - temas activos
  - plugins personalizados

## Qué NO está incluido
- WordPress core (`wp-admin`, `wp-includes`, archivos raíz de WordPress)
- datos de usuario y medios (`wp-content/uploads`)
- caché y backups
- archivos de configuración local (`wp-config.php`)

> Esta versión del repositorio está optimizada para almacenar solo el código útil del sitio.
